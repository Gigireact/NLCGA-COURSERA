# NLCGA IGNITE landing page

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # output in dist/
```

- Images/logos: add files to `src/assets/images`, import them in `src/assets/index.js`.
- PDFs: put `learning-needs-survey.pdf` and `coursera-order-form.pdf` in `public/downloads`.
- Content lists: `src/data/index.jsx`. Styles: `src/styles/ignite.css`.
- Placeholders to fill: programme dates and secretariat address.
